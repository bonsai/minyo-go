スポット一覧

スポット追加

歌とのつながりが確認できた場所を足せます。追加分はこのブラウザ（localStorage）に保存され、地図・一覧・メダル対象に即反映されます。緯度・経度は空でも登録できます（その場合は座標未確認として一覧のみ表示）。

追加分の書き出し

追加したスポットを、台帳 spots-verified.json と同じ形式の JSON で書き出せます。書き出した JSON を repo の台帳へマージして push すると、みんなの歌mapにも反映されます（運用は README 参照）。

スポットクイズ

メダルと追加スポットはこのブラウザの localStorage に保存されます。通常モードのメダルGETは現在地から30km圏内のみ。テストモードでは距離制限なしで取得できます。
